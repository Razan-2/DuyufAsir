# ضيوف عسير — منصة متعددة الوكلاء الذكيين

«ضيوف عسير» منصة متكاملة وبسيطة تجمع خمسة وكلاء ذكيين متخصصين، وتوجّه طلب المستخدم إلى الوكيل المناسب.

## المميزات

- واجهة خلفية مبنية باستخدام FastAPI
- تفعيل CORS لبيئة التطوير
- التحقق من الطلبات باستخدام Pydantic
- خمسة وكلاء متخصصين
- واجهة عربية متجاوبة مبنية باستخدام HTML وCSS وJavaScript
- معالجة واضحة لحالات النجاح والخطأ
- بنية منظمة قابلة للتوسع وربط نماذج ذكاء اصطناعي حقيقية لاحقًا

## هيكل المشروع

```text
Wukala/
├── main.py
├── requirements.txt
├── README.md
└── frontend/
    ├── index.html
    ├── style.css
    └── script.js
```

## الإعداد

أنشئ بيئة افتراضية ثم ثبّت المتطلبات:

```bash
python -m venv .venv
```

على Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

على macOS أو Linux:

```bash
source .venv/bin/activate
pip install -r requirements.txt
```

## تشغيل الواجهة الخلفية

من داخل مجلد `Wukala` شغّل:

```bash
uvicorn main:app --reload
```

ستعمل الواجهة البرمجية على `http://127.0.0.1:8000`.

## تشغيل الواجهة الأمامية

افتح نافذة أوامر أخرى وشغّل:

```bash
python -m http.server 5500 --directory frontend
```

ثم افتح `http://127.0.0.1:5500` في المتصفح.

## مسارات الواجهة البرمجية

- `GET /` يعرض حالة الخادم.
- `GET /agents` يعرض جميع الوكلاء المتاحين.
- `POST /chat` يستقبل معرّف الوكيل ورسالة المستخدم.

مثال على الطلب:

```json
{
  "agent": "housing",
  "message": "أحتاج إلى مكان للإقامة لمدة ليلتين."
}
```

الردود الحالية محاكاة أولية، ويمكن استبدالها لاحقًا بنموذج ذكاء اصطناعي أو نظام توجيه متقدم.
